# Гости

Веб-приложение со списком гостей: карточки с фото, поиском и фильтром по категориям.

## Запуск

```bash
npm install
npm run dev
```

Откроется на http://127.0.0.1:5173/

## Данные

Все гости и тексты лежат в `src/entities/guest/model/guests.ts`.  
Фотографии — в `public/guests/`.

## Скрипты

- `npm run dev` — локальная разработка
- `npm run build` — продакшен-сборка
- `npm run typecheck` — проверка типов
